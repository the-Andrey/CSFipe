# CSFipe

## Descrição
O CSFipe é um app que possibilita acesso ao histórico de diversos veículos com dados baseados na tabela FIPE. A tabela FIPE é a referência para precificação de veículos no Brasil, sendo atualizada mensalmente e fornecendo valores médios de carros, motocicletas e caminhões.
Os dados são disponibilidados através da API FIPE ONLINE, que você pode acessar [aqui](https://fipe.online/), essa API oferece os dados da tabela FIPE de forma rápida e confiável, além de ser gratuita. A API possui também planos diferentes que permitem limites diferentes de requisiçòes diárias, você pode consguir mais informações acessando o [site oficial](https://fipe.online/).
